# Checklist de Acessibilidade

Este documento consolida os critérios verificáveis de interface definidos na spec de `acessibilidade-leitura`.

- [ ] **Contraste de texto:** A interface cumpre o contraste mínimo de 4,5:1 para texto.
- [ ] **Tamanho da fonte:** A fonte base possui no mínimo 18px.
- [ ] **Responsividade da fonte:** O texto é responsivo ao ajuste de tamanho do sistema (ex: texto acompanha ampliação sem corte ou sobreposição).
- [ ] **Alvo de toque:** Os elementos interativos (botões, links) possuem alvo de toque de no mínimo 44px.
- [ ] **Ação primária:** Existe uma única ação primária claramente identificável por tela, alcançável sem rolagem horizontal mesmo sob zoom.
